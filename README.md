# ふふっと富山のフォトマップ（初期版）

## 起動方法
1. このフォルダを VS Code で開く
2. VS Code の拡張機能「Live Server」をインストール
3. `index.html` を右クリック → `Open with Live Server`

地図ライブラリ・地図タイル・Google Fontsの読み込みにインターネット接続が必要です。

## 写真を追加する
1. 写真ファイルを `images` フォルダへ入れる
2. `script.js` の `PHOTOS` 配列に写真データを追加する
3. 写真が属する撮影場所の `spotId` を設定する

## 撮影スポットを追加する
`script.js` の `SPOTS` 配列に、固有の `id`、表示番号 `number`、名前、エリア、緯度 `lat`、経度 `lng`、説明、外部地図URLを追加します。
写真の `spotId` は、対応するスポットの `id` と一致させてください。

## 注意
- 現在の緯度・経度は動作確認用の仮データです。実際の撮影地点ではありません。公開前に必ず正しい位置へ修正してください。
- `images/spot01-01.jpg` などのサンプル画像ファイルは同梱していません。画像がない場合はプレースホルダーが表示されます。
- OpenStreetMap の標準タイルを利用しています。利用時は帰属表示・タイル利用ポリシーを守ってください。
- 写真は撮影者の権利、写り込んだ人物のプライバシー、現地の撮影ルール、安全に配慮して掲載してください。
